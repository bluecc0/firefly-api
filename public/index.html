如何获取 Bearer Token？
  1. 浏览器登录 firefly.adobe.com
  2. 按 F12 → Network → 找到发往 firefly-3p.ff.adobe.io 的请求（如 generate-async 或 models/discovery）
  3. 在 Request Headers 中找到 Authorization，复制 Bearer 后面以 eyJ 开头的完整字符串粘贴到上方即可。
